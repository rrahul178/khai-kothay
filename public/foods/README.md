# Food photos

Drop photos here named after the food slug, then set `image` on that food in `src/data/foods.ts`:

    { slug: "kacchi-biryani", ..., image: "/foods/kacchi-biryani.jpg", imageCredit: "Photo: <author>, CC BY-SA 4.0" }

Use only photos you own or that carry a licence allowing reuse (and keep the credit text the licence requires).
Recommended: 800x600 JPG/WebP, under 150 KB each. Foods without a photo show an illustrated tile automatically.
